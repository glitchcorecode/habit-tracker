Отчет по разработке проекта «Трекер привычек»

ФИО: Мурзажанов Алишер Муталипжонович
Группа: МИП-2
Ссылка на репозиторий: https://github.com/glitchcorecode/habit-tracker

В данном репозитории собрана история выполнения нескольких практических работ. Ниже описан весь путь развития проекта от базового каркаса до добавления новых функций и разрешения конфликтов.

1. Первый этап: создание базового проекта
Был создан каркас веб-приложения (Трекер привычек) на базе HTML, CSS и Vanilla JavaScript. В качестве хранилища данных используется localStorage, что позволяет сохранять привычки при перезагрузке страницы. Базовый интерфейс был сверстан в темных тонах, реализовано добавление, удаление привычек и автоматический сброс галочек на следующий день с переносом статистики в архив.

2. Второй этап: первая пользовательская функция
В рамках изучения работы с ветками Git, была создана ветка feature/first-feature. В нее добавлена функция редактирования привычки. Реализовано это через двойной клик по тексту привычки: открывается диалоговое окно, где можно изменить название. Добавлена защита от пустого ввода и отмены действия.

3. Третий этап: вторая функция и рефакторинг кода
В ветке feature/second-feature была добавлена вторая функция — поиск. Над списком появилось поле ввода, которое в реальном времени фильтрует привычки по названию.
Также был проведен рефакторинг. Изначально функция updateUI() была перегружена кодом. Я вынес создание HTML-элемента привычки (сборку тегов li, span, button и навешивание обработчиков) в отдельную функцию createHabitElement(habit). Это сделало код чище и разделило ответственность функций, при этом старое поведение программы полностью сохранилось.

4. Четвертый этап: учебный конфликт Git
Для отработки слияния веток был искусственно создан конфликт. Были созданы две ветки от main (fix/text-1 и fix/text-2). В обеих ветках изменялся текст подзаголовка в файле index.html.
При слиянии Git выдал конфликт. Вручную были удалены маркеры <<<<<<<, ======= и >>>>>>>, а текст объединен в единый осмысленный вариант: "Твой персональный трекер привычек и ежедневных задач.". После этого был сделан финальный merge-коммит.

5. Текущий статус проекта
Все изменения успешно слиты в основную ветку main и отправлены на GitHub. История коммитов содержит все этапы разработки. В настоящий момент проект работает корректно: поиск фильтрует список, старые функции (добавление, удаление, редактирование) не сломаны, конфликтов в коде нет. Git status чистый.
